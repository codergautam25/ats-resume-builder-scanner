# Awesome DESIGN.md — Brand Design System Skill

`awesome-design-md` provides authoritative `DESIGN.md` blueprints from 74+ leading technology and luxury brands. Use these blueprints to enforce high-end visual aesthetics, typography ramps, component tokens, and motion guidelines.

## Available Brand Design System Blueprints
All blueprints are located in `design-md/<brand>/DESIGN.md`:

- **Vercel** (`design-md/vercel/DESIGN.md`): Monochromatic luxury, Geist font family, subtle borders, high contrast.
- **Stripe** (`design-md/stripe/DESIGN.md`): Vibrant mesh gradients, ultra-sleek typography, micro-interactions, high trust.
- **Linear** (`design-md/linear.app/DESIGN.md`): Dark tech elegance, keyboard-first density, restrained motion, indigo/purple glow effects.
- **Apple** (`design-md/apple/DESIGN.md`): Fluid physical motion, translucent glass materials (`backdrop-filter`), San Francisco typography, spatial depth.
- **Raycast** (`design-md/raycast/DESIGN.md`): Command-bar interface, high-density dark mode, subtle neon accents.
- **Claude / Anthropic** (`design-md/claude/DESIGN.md`): Warm terracotta/cream editorial palette, elegant serif/sans contrast.
- **Notion** (`design-md/notion/DESIGN.md`): Minimalist, document-first, tactile borders, clear hierarchy.
- **Resend** (`design-md/resend/DESIGN.md`): Deep black background, emerald/indigo accents, crisp grid lines.
- **Superhuman** (`design-md/superhuman/DESIGN.md`): Ultra-fast keyboard UI, gold/purple luxury accents.

## How to Apply a Brand Design System
1. Read the target `DESIGN.md` file from `design-md/<brand>/DESIGN.md`.
2. Apply color tokens, typography hierarchy, border-radius tokens, and layout guidelines directly to CSS variables or Tailwind CSS classes.
3. Ensure dark and light themes preserve exact contrast ratios and brand characteristics.
